# コールセンター ナレッジベース

社内のコールセンター向けに、お問い合わせ対応で必要な情報をまとめた静的サイトです。
ビルド不要で、ブラウザで HTML ファイルを開くだけで利用できます。データは各ブラウザの
localStorage に保存されます（サーバー側の永続化は行いません）。

## ファイル構成

- `index.html` - メイン画面（各機能への入り口とサマリー表示）
- `faq.html` - FAQ の登録・検索
- `flow.html` - 技術切り分けフロー（質問に答えていくと対応手順を案内）
- `escalation.html` - 手上げ（エスカレーション）記録
- `claim.html` - クレーム対応事例の登録・検索
- `css/style.css` - 共通スタイル
- `js/storage.js` - localStorage 用の共通ユーティリティ

## 使い方

`index.html` をブラウザで開いてください。各ページのナビゲーションから
FAQ・切り分けフロー・手上げ記録・クレーム対応事例にアクセスできます。
