# コールセンター ナレッジベース

社内のコールセンター向けに、お問い合わせ対応で必要な情報をまとめた静的サイトです。
ビルド不要で、ブラウザで HTML ファイルを開くだけで利用できます。データは各ブラウザの
localStorage に保存されます（サーバー側の永続化は行いません）。

## ファイル構成

- `index.html` - メイン画面（各機能への入り口とサマリー表示、手上げ率の目標値）
- `faq.html` - FAQ の登録・検索
- `flow.html` - 技術切り分けフロー（質問に答えていくと対応手順を案内。技術切り分け・V6システム関連を重点的にカバー）
- `criteria.html` - 判断基準表（自己判断OK／SVに確認／即エスカレ の境界線を一覧化）
- `escalation.html` - 手上げ（エスカレーション）記録、カテゴリ別集計
- `claim.html` - クレーム対応事例の登録・検索
- `css/style.css` - 共通スタイル
- `js/storage.js` - localStorage 用の共通ユーティリティ、共通カテゴリ・初期データ

## カテゴリ構成

FAQ・切り分けフロー・判断基準表・手上げ記録は、手上げ内訳の分析に基づく以下7カテゴリで統一しています。

- 技術切り分け（約30%）
- V6システム関連（約20%）
- 例外案件（約20%）
- クレーム対応（約10%）
- 工事関連（約10%）
- 契約確認（約5%）
- システム操作（約5%）

## 使い方

`index.html` をブラウザで開いてください。各ページのナビゲーションから
FAQ・切り分けフロー・判断基準・手上げ記録・クレーム対応事例にアクセスできます。
